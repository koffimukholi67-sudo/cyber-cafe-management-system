# Cyber Cafe Management System

## Developer
Koffi Mukholi Nyongesa

## Description
A Python-based Cyber Cafe Management System designed
to manage customer transactions and monitor business income.

## Features
- Customer transaction recording
- Printing and photocopying services
- Customer transaction history
- Automatic income calculation
- CSV record storage

## Technology Used
- Python
- CSV
- Datetime
- Operating system file handling

## How to Run
1. Install Python 3.
2. Download cyber_cafe.py.
3. Open a terminal.
4. Run:

python cyber_cafe.py

## Purpose
This project demonstrates practical programming,
file handling, data management and problem-solving skills.
